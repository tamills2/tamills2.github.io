Ephemeral port defaults

Ephemeral ports are temporary local source ports selected by the operating system for outbound connections. These defaults can be changed by administrators or software.

Operating systemDefault rangeNotes
Linux32768–60999Kernel default for TCP and UDP local-port selection through ip_local_port_range. Distribution or host settings may override it.
Windows Vista / Server 2008 and newer49152–65535Modern Windows default. TCP and UDP ranges are configured separately for IPv4 and IPv6.
Windows XP / Server 2003 and older1025–5000Legacy Windows default retained here for troubleshooting older systems and mixed environments.

View or change the active range

Linux — view with procfscat /proc/sys/net/ipv4/ip_local_port_range
Linux — view with sysctlsysctl net.ipv4.ip_local_port_range
Linux — set temporarilysudo sysctl -w net.ipv4.ip_local_port_range="32768 60999"
Windows — view IPv4 TCPnetsh int ipv4 show dynamicport tcp
Windows — view IPv4 UDPnetsh int ipv4 show dynamicport udp
Windows — restore modern TCP defaultnetsh int ipv4 set dynamicport tcp start=49152 num=16384

Changing the range can affect firewalls, NAT, RPC, and high-connection workloads. Check the active host configuration before relying on a default.

Important notes

Port numbers identify conventional service endpoints, not guaranteed behavior. Applications can be configured on different ports, and an open port does not prove that the expected service is running.

Some services use both TCP and UDP, multiple control/data channels, or additional dynamically negotiated ports. Firewall rules should be based on the actual application and network design.
