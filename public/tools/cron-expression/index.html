Paste a five-field Unix cron expression. Names such as MON and JAN are supported.

Field reference

Standard Unix crontab syntax uses five schedule fields followed by the command.

minute hour day-of-month month day-of-week
*Any value
,List: 1,15,30
-Range: 1-5
/Step: */10

This tool targets standard five-field Unix cron. Quartz, Jenkins, AWS/EventBridge, and other schedulers may use different field counts or rules.
