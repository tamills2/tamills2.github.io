ASCII HOMEPAGE ARTWORK

Each artwork is stored in its own .txt file. Metadata lives in manifest.json.

ADDING A NEW SCENE
1. Copy _template.txt to a lowercase-hyphenated filename, such as gargoyle.txt.
2. Replace the guide with the artwork. Do not include an outer frame unless it is part of the art.
3. Add an object to manifest.json with id, heading, subtitle, and file.
4. Rebuild the site.

RECOMMENDED CANVAS
- Up to 72 columns wide and 22 lines tall.
- Use spaces, not tabs.
- Equal dimensions are optional. They make transitions steadier, but the page measures and centers every artwork automatically.
- Shared leading indentation is removed automatically.
