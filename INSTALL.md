# Build script rename

## Create or replace

Copy these files into the matching locations:

```text
scripts/build_site.py
.github/workflows/deploy-pages.yml
public/tools/template/README.md
```

## Delete

Remove the old script:

```text
scripts/generate_notes_manifest.py
```

Do not delete the generated JSON files. They are still the files read by the
static site:

```text
public/data/notes-manifest.json
public/data/tools-manifest.json
public/data/site-search-index.json
```

They will now be regenerated by:

```bash
python3 scripts/build_site.py
```

The GitHub Pages deployment workflow included in this update already uses the
new command.

## New-tool workflow

For future tools, create only:

```text
public/tools/<tool-name>/
├── index.html
├── tool.json
├── tool.js      # only when needed
└── tool.css     # only when needed
```

Then run:

```bash
python3 scripts/build_site.py
```

The build script discovers visible tools automatically and regenerates the
notes manifest, tools manifest, and global search index.
